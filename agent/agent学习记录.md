## **达人推荐 Agent 学习路线**

1. **第一阶段：LLM 基础**
    
    必须掌握
    
    - Prompt Engineering
        
    - Function Calling / Tool Calling
        
    - Structured Output
        
    - Embedding
        
    - RAG
        
    - 上下文窗口和 Token
        
    
2. **第二阶段：LangChain**
    
    必须掌握
    
    - Chat Model
        
    - Prompt Template
        
    - Tools
        
    - Agent
        
    - Structured Output
        
    - Retriever
        
    
3. **第三阶段：LangGraph**
    
    重点掌握
    
    - State
        
    - Node
        
    - Edge
        
    - Conditional Edge
        
    - Checkpoint
        
    - Interrupt
        
    - Subgraph
        
    - Multi-Agent
        
    
4. **第四阶段：MCP**
    
    建议掌握
    
    - MCP Client
        
    - MCP Server
        
    - Tools / Resources
        
    - 工具权限
        
    - MCP 与业务 API 的关系
        
    
5. **第五阶段：RAG 和数据检索**
    
    - LlamaIndex
        
    - Embedding 模型
        
    - 向量检索
        
    - 混合检索
        
    - Reranker
        
    - 知识库构建
        
    
6. **第六阶段：生产级 Agent**
    
    - LangSmith
        
    - Agent 评估
        
    - 并发控制
        
    - 超时和重试
        
    - 状态持久化
        
    - 成本控制
        
    - 人工审核

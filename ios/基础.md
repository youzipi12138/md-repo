# 十、如果你要开始学习 iOS，建议按什么顺序？

你现在这份代码已经涉及 SwiftUI 项目里的基础设计了。我建议你按照下面的路线学习，不要一开始就直接钻进复杂的项目架构。

1. 第一阶段：Swift 语言基础
    
    先掌握 `let`、`var`、基本类型、`if`、`switch`、循环、函数、枚举、结构体、类、可选类型。
    
2. 第二阶段：SwiftUI 界面开发
    
    学习 `View`、`Text`、`Image`、`Button`、`VStack`、`HStack`、`ZStack`、`List`、`TabView`。
    
3. 第三阶段：状态管理
    
    学习 `@State`、`@Binding`、`@Observable`，理解数据变化如何驱动界面更新。
    
4. 第四阶段：页面导航与网络请求
    
    学习 `NavigationStack`、页面传值、`URLSession`、JSON 解码，以及登录接口的接入。
    
5. 第五阶段：真实项目结构
    
    再学习 MVVM、网络层封装、数据持久化、登录状态管理、模块拆分和测试。
    

如果你之前学过 React，那么学习 SwiftUI 时可以重点关注这个对应关系：

| React / TypeScript | Swift / SwiftUI            |
| ------------------ | -------------------------- |
| TypeScript 类型      | Swift 类型系统                 |
| 联合类型               | 枚举可以表达类似的有限选项              |
| `interface`        | Swift `protocol`，但两者并不完全等价 |
| React 组件           | SwiftUI `View`             |
| `useState`         | `@State`，用途相近但机制不同         |
| `map()` 渲染列表       | `ForEach`                  |
| JSX 声明式 UI         | SwiftUI 的 `body` 声明式 UI    |
